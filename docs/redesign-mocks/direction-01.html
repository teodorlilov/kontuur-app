Motion

Four speeds, one temperament

Everything animated in the product uses one of these four tokens — hover the demos. All of it is CSS and Framer Motion; no generated video, nothing that costs bytes.

Micro 120 ms · ease-out Hovers, presses, focus rings — everywhere, including the dashboard hover
Base 200 ms · ease-out-quart Fades, reveals, toasts hover
Overlay 260 ms · soft spring Dialogs, dropdowns, popovers — scale from 97% hover
Ambient 20–40 s · linear Landing hero aurora only — never inside the app ambient
The landing page is orchestrated — load sequence, scroll reveals, marker draws.
The dashboard is micro only — route changes never animate, so navigation stays instant.
Reduced motion is respected — every effect collapses to a simple state change.

What to check

  • Is Forest #164430 the right darkness, or should the green lean warmer / colder?
  • Is the amount of serif italic right — more voice, or less?
  • Motion temperature — calmer, or one notch bolder?
  • Does the dashboard slice feel like a place you'd work all day?

How this ships

  • Every value on this page becomes a Tailwind 4 token — the mock is the design system.
  • Geist is already in production; Instrument Serif is one small font file away.
  • Next step after approval: full-page mocks — landing, sign-in, one dashboard tab.
