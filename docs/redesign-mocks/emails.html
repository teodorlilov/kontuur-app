Decisions behind this, and what it costs

Why the fonts are not Geist and Instrument Serif

Gmail, Outlook and most webmail strip custom web fonts out of email entirely, and embedding them inflates the message past Gmail's 102KB clipping limit. So the send uses Georgia italic where the design calls for Instrument Serif, and the system sans stack where it calls for Geist. Georgia is the closest widely-installed match to Instrument Serif's high-contrast italic, and it carries the same gesture. Apple Mail users will see it identically to what's mocked above; nobody sees a broken fallback.

What could not come across from direction-01

  • The drifting aurora behind the hero — email clients don't run animation or blur filters. The Pine Deep plate carries the brand weight instead.
  • The reveal-on-scroll motion. Nothing moves in an inbox.
  • The contour field on paper. It would be a background image, which Outlook drops and which costs the size budget. The near-white paper ground is kept.

Where the lime sits

One mark only: the full stop after the wordmark, on Pine Deep. That respects the Fill-Only Lime Rule — lime is unreadable at 1.35:1 on a light ground, and legitimate on Pine Deep where the relationship inverts. The uppercase label opposite it uses Living Green Lite, which is the dark-surface green.

The invite email needs one code change to say this much

The invite currently passes { invited_agency_id, role } to Supabase — an id, not a name — so a template has nothing to print. Naming the agency means also passing agency_name, then reading {{ .Data.agency_name }} in the template. Without it, the copy falls back to "You've been invited to a workspace on Kontuur", which is noticeably thinner.

What changes in the codebase

  • The shell above becomes one function. The four bodies are the only thing that differs, so the plate, card, button and footer are written once and the approval email is rewritten to use it.
  • The three Supabase templates are the same markup with {{ .ConfirmationURL }} in place of the button link, stored as files under supabase/templates/ so they live in git rather than only in the dashboard.
  • Supabase's SMTP settings point at Resend, which is what stops "Supabase Auth" being the sender.
